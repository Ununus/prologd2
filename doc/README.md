# Документация PrologD

В этом каталоге лежат три документа на языке Typst:

| Файл | Назначение |
|------|------------|
| `help.typ` | руководство пользователя: синтаксис, типы данных, все встроенные предикаты, примеры, командная строка |
| `technical.typ` | техническое описание: модель термов, унификация, машина вывода, длинная арифметика, разбор, модули, тестирование |
| `prologd-diff.typ` | изменения синтаксиса и поведения относительно первоначального Пролога-Д, с примерами «было/стало» |

Документы написаны на русском языке; комментарии и идентификаторы в примерах кода
приводятся без изменений.

## Сборка PDF

Для сборки нужен компилятор [Typst](https://typst.app/) (`typst`). Если он
установлен, достаточно выполнить из корня проекта:

```sh
cmake --build build --target docs
```

PDF-файлы появятся в `build/doc/`. Можно собрать и вручную:

```sh
typst compile doc/help.typ        doc/help.pdf
typst compile doc/technical.typ   doc/technical.pdf
typst compile doc/prologd-diff.typ doc/prologd-diff.pdf
```

Если `typst` не установлен, его можно поставить как Python-пакет (компилятор
входит в пакет):

```sh
python3 -m venv .venv && .venv/bin/pip install typst
.venv/bin/python -c "import typst; typst.compile('doc/help.typ', output='doc/help.pdf')"
```

Если `typst` недоступен, цель `docs` просто выводит сообщение и завершается
успешно: сборка интерпретатора от документации не зависит.

## Как поддерживать документацию в актуальном состоянии

* Новый встроенный предикат добавляется в `help.typ` в том же изменении, что и
  его реализация.
* Любое изменение синтаксиса или наблюдаемого поведения языка фиксируется в
  `prologd-diff.typ` с примером «было/стало».
* Внутренние решения (структуры данных, алгоритмы, компромиссы) описываются в
  `technical.typ`; краткие решения---в `ai/decisions.md`.
