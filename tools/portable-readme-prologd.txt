Пролог-Д 1.27 — переносная сборка для Windows
==============================================

Что это.  Окно и интерпретатор первоначального Пролог-Д — того самого движка,
который лежит в репозитории https://github.com/Ununus/prologd.  Ничего
устанавливать не нужно: папку можно скопировать целиком, например на флешку.

Запуск
  prologd-gui.exe   окно: редактор, запуск программы по F5, ответы в панели внизу.
  prologd.exe       интерпретатор в командной строке:
                      prologd.exe --source=examples\factorial.pld
                      prologd.exe --help
  Окно берёт интерпретатор из своей же папки, настраивать ничего не надо.

В этой сборке один движок — первоначальный Пролог-Д, поэтому на панели нет
переключателя состояния (движка и имён переменных): выбирать нечего.  Файл
настроек, принесённый с другой машины, окно тоже не собьёт: сборка всегда
открывается на том движке, что лежит рядом с ней.  Команды, которых этот движок
не умеет (форматирование, шаг, трассировка, графический экран), выключены.

Программы — в папке examples: это файлы из репозитория Пролог-Д, как есть.
Уроки первоначального курса — в examples\lessons (имена файлов содержат пробелы,
поэтому в командной строке их надо брать в кавычки):
    prologd.exe --source="examples\lessons\lesson 1.pld"
Библиотека курса — в examples\lib; пример ИМПОРТ открывает её по пути
examples/lib/library.pld, поэтому этот пример запускают из папки самой сборки.

Документация — в папке doc: help.pdf (язык и встроенные предикаты, из
репозитория Пролог-Д) и gui.pdf (окно).  В окне: руководство — Shift+F1, справка
по предикату — F1 (она читает doc\builtins.json).

Настройки окна — файл gui.ini рядом с prologd-gui.exe (создаётся при первом
запуске).  Чтобы вернуть всё как было, файл можно удалить.

Требуется Windows 10 (1903) или новее, 64 bit: окно построено на Qt 6 и Python
3.14, которым нужна Windows 10, а манифест UTF-8 понимают начиная с 1903.
На Windows 7 сборка не запустится.
