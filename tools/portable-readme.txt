Пролог-Д 2.0 — переносная сборка для Windows
============================================

Что это.  Два исполняемых файла, документация и примеры.  Ничего устанавливать не
нужно: папку можно скопировать целиком, например на флешку.

Запуск
  prologd-gui.exe   окно: редактор, запуск программы по F5, ответы в панели внизу.
  prologd.exe       интерпретатор в командной строке:
                      prologd.exe -s examples\lessons\lesson_01.pld
                      prologd.exe --help
  Окно берёт интерпретатор из своей же папки, настраивать ничего не надо.

Уроки и примеры — в папке examples: уроки в examples\lessons, библиотека для урока
про ИМПОРТ — в examples\lib.  Открыть урок в окне: «Файл → Открыть» (Ctrl+O),
запустить — F5, ответы — в панели «Вывод» (и таблицей на вкладке «Таблица»).  Вопрос
на полях выполняется щелчком по синему треугольнику.

Библиотеку для урока про ИМПОРТ окно ищет само: папка examples\lib уже в списке
поиска, настраивать ничего не надо — и папку можно переносить куда угодно.

Документация — в папке doc: help.pdf (язык и встроенные предикаты), gui.pdf (окно),
lessons.pdf (курс), technical.pdf (устройство), prologd-diff.pdf (отличия от
первого Пролог-Д).  Исходники .typ лежат рядом — для чтения они не нужны.
В окне: руководство — Shift+F1, справка по предикату — F1.

Настройки окна — файл gui.ini рядом с prologd-gui.exe (создаётся при первом
запуске).  Чтобы вернуть всё как было, файл можно удалить.

Требуется Windows 10 (1903) или новее, 64 bit: окно построено на Qt 6 и Python
3.14, которым нужна Windows 10, а манифест UTF-8 понимают начиная с 1903.
На Windows 7 сборка не запустится.
