# task_93 — Одна кнопка состояния: движок и имена одним переключателем

**Status:** done (2026-10-22) — часть 151 в `ai/status.md`
**Depends on:** task_79 (кнопка смены движка), task_67/task_77 (режимы имён), task_88
**ADR:** `ai/decisions.md`, ADR-029

## Зачем

В правом углу панели стояли две кнопки состояния, и обе — значками: `n.png` («имена»)
открывала меню двух диалектов, `u.png`/`d.png` переключала движок.  Значки надо было
расшифровывать, и первый же читатель пакета принял `Д` за «Пролог-Д 2.0» — то есть за
название всей программы, а не за оригинальный движок.  Подписи с номерами выпусков
добавляли путаницы: `2.0` — версия оболочки, интерпретатор 2.4.x, а закреплённый
оригинальный репозиторий объявляет `VERSION 1.27` — число, которое раньше означало январь
2026 года.

Практически состояний, в которых может быть окно, три: наш движок с именами ISO, наш
движок со старыми именами и оригинальный движок (у него режимов нет вовсе).

## Что сделано

* Таблица `actions.STATES` и маркер `actions.STATE` вместо `NAMING`/`ENGINE`:
  `2.x ISO`, `2.x PLD`, `1.x` — линия движка, а не номер выпуска (так же называет столбцы
  таблица сравнения в `doc/help.typ`).
* Картинки — сами слова: `engine-iso.png`, `engine-pld.png`, `engine-1.x.png` (временные,
  будут перерисованы).  Пропавший файл оставляет кнопку с текстом, а не пустую.
* `window._build_state_button` / `_sync_state_button` / `_sync_state_menu` /
  `_choose_state`; `switch_engine` стал `choose_engine(target)` — одна дверь смены
  движка, которая по-прежнему сначала останавливает сессию.
* Меню: две `2.x` строки берут слова из строки «Имена переменных» (хвост после её
  `ISO:`/`PLD:`), третья — «1.x: оригинальный движок».  Строка, ведущая к движку,
  которого в сборке нет, выключена; в сборке с одним движком без `NAMING` кнопки нет.
* `engines.Engine.icon` удалён: значки теперь у состояний.

## Поведение, которое нельзя было потерять

* `2.x ISO` ↔ `2.x PLD` — только `execution/variable_mode`: подсветка сразу, сессия жива.
* `1.x` (и любая `2.x` под оригинальным движком) — смена программы: остановка сессии,
  запись `view/engine`, перечитывание `--list-keywords`.
* Выбор `1.x` не переписывает сохранённый диалект: возврат на `2.x` даёт прежний.
* Маркер `:- ИМЕНА(N).` в файле важнее любой кнопки.
