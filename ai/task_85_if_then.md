# task_85 — `->`: если-то и если-то-иначе

**Status:** done (2026-10-13)
**Depends on:** task_41 (`;` стал дизъюнкцией), task_51 (`ПЕРВОЕ`), task_55 (`\+`)

## Зачем

Просьба владельца: «Добавим `->`.»  В ISO-Прологе «если-то» пишут знаком `->`, и он
оставался единственной записью того, что диалект умел только словами:
`ПЕРВОЕ(Условие), Тогда` и правило с отсечением.  На `->` диалект отвечал
подсказкой «не оператор, пишите `ПЕРВОЕ`» (task_52); подсказка убрана.

## Семантика

* `(Условие -> Тогда)` берёт *первое* решение условия (остальные теряются, как при
  отсечении) и выполняет следствие.  Решений у условия нет — неудача.
* `(Условие -> Тогда ; Иначе)`: здесь `;` после `->` значит «иначе», и это **не**
  дизъюнкция.  Если у условия есть решение, ветвь «иначе» отпадает навсегда — даже
  когда следствие не решается.  Ровно этого не выразить ни `;` с отсечением
  (отсечение ветви локально ей самой), ни `ПЕРВОЕ(C), T ; Иначе` (там «иначе»
  возьмётся, когда `T` не решилось).
* Приоритет как в ISO: `,` связывает крепче `->`, `->` крепче `;`, оба
  правоассоциативны — `A -> T ; B -> U ; E` читается как `(A -> T) ; ((B -> U) ; E)`.
* Условие-конъюнкцию берут в скобки: `A, B -> C` — это `(A, B) -> C`, а `A, (B -> C)`
  пишется скобками явно.
* Отсечение внутри условия наружу не выходит: условие решается в машине своего
  уровня (`Engine::callOnce`), как у `НЕ` и `ПЕРВОЕ`.

## Что сделано

* Лексер: `TokenKind::IfThen`, два байта `->` читаются как один знак **до** таблицы
  чужих записей; строка про `->` из `kForeignOperators` убрана.
* Разбор: `Parser::parseGoalExpression` (`;`) и `Parser::parseIfThen` (`->`) — три
  уровня целей вместо двух, оба знака правоассоциативны; тот же вход у скобочной
  цели (`ВЫП((A -> B ; C))`, `НАЙТИВСЕ(X, (A -> B), L)`).  Пустой знак
  (`?A -> .`) даёт своё сообщение «после «->» нужна цель», а не «цель должна быть
  предикатом».
* Решатель (`resolveGoal`): `->` берёт условие через `callOnce` и передаёт следствие
  дальше; `;(->(C,T), E)` узнаётся до общей дизъюнкции — ветвь «иначе» кладётся
  точкой выбора **до** решения условия, и условие, у которого нашлось решение,
  снимает эту точку (`dropChoicePoints`).  Это и есть отсечение ветви «иначе».
* Проверки: `walkGoal` раскрывает обе стороны `->`, как у `;`, — имена внутри
  условия и следствия проверяются.
* Форматтер: `->` размечен как `;` — пробелы с двух сторон и точка переноса жёсткой
  формы.
* Окно: `tokens.py` читает `->` одним знаком (иначе видит `-` и `>`), проверка в
  `test_tokens.py`.
* Проверки C++: `test_builtins_control.cpp` (поведение, включая «иначе не берётся»),
  `test_parser.cpp` (приоритет и правоассоциативность), `test_lexer.cpp`,
  `test_diagnostics.cpp` (пустой знак), `test_formatter.cpp` (пробелы и переносы).
* Документы: `help.typ` §4.5 и §4.6 (знак вместо советов), строка таблицы сравнения,
  `prologd-diff.typ` (строка сводной таблицы и раздел «`->` — если-то и
  если-то-иначе»), `technical.typ` §5.4 (как устроено в решателе).

## Проверки

`ctest` 345 → **348**; 25 оконных сюит и `protocol_smoke.py` зелёные; шесть
документов собираются без замечаний.  Руками на собранном движке (цены: `хлеб 40`,
`молоко 20`):

| Запрос | Ответ |
|--------|-------|
| `?цена(Т, Ц) -> Ц < 100.` | `Т=хлеб`, `Ц=40` — одно решение |
| `?цена(Т, Ц) -> Ц < 30.` | `НЕТ` — условие решено, следствие нет |
| `?(цена(Т, Ц), Ц < 30) -> РАВНО(1, 1).` | `Т=молоко`, `Ц=20` |
| `?(цена(Т, Ц), Ц > 100) -> Т = дорого ; Т = иначе.` | `Т=иначе` |
| `?(цена(Т, Ц) -> Ц > 100 ; Т = иначе).` | `НЕТ` — «иначе» отпало |
| `?ЛОЖЬ -> РАВНО(X, 1).` | `НЕТ` |
| `?ЛОЖЬ -> РАВНО(X, 1) ; РАВНО(X, 2).` | `X=2` |
| `?ЛОЖЬ -> РАВНО(X, 1) ; ЛОЖЬ -> РАВНО(X, 2) ; РАВНО(X, 3).` | `X=3` |
| `?п(X) -> РАВНО(Y, X) ; РАВНО(Y, 0).` | `X=1`, `Y=1` |
| `?ВЫП((цена(Т, Ц) -> Ц < 30 ; Т = иначе)).` | `НЕТ` |
| `?НАЙТИВСЕ(Т, (цена(Т, Ц) -> Ц < 30 ; Т = иначе), L).` | `L=[]` |

Форматтер (замерено, `--format=line` и `--format=hard`):
`выбор(Х):-дешёвый(Х)->надёжный(Х);отложить(Х).` → `выбор(Х):-дешёвый(Х) -> надёжный(Х) ; отложить(Х).`,
а жёсткая форма разбивает тело по обоим знакам; запрос остаётся одной строкой.
