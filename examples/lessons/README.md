# Уроки Пролог-Д

Тринадцать файлов курса: двенадцать уроков и приложение по отладке. Каждый урок —
самостоятельная программа: его можно запустить целиком, прочитать комментарии и
тут же увидеть, что печатает интерпретатор.

## Как читать урок

Строка с `?` — это запрос, а строки `%!` под ней — ровно то, что интерпретатор
печатает. Запустить урок целиком:

```sh
prologd -s examples/lessons/lesson_01.pld
```

Двум урокам нужна добавка:

```sh
# урок 7 читает ответы из файла рядом с собой
prologd -s examples/lessons/lesson_07.pld < examples/lessons/lesson_07.input.txt

# урок 11 подключает библиотеку из examples/lib
prologd -I examples/lib -s examples/lessons/lesson_11.pld
```

## Проверка

Уроки проверяются тестом `every lesson prints exactly what its comments promise`
в `src/tests/test_lessons.cpp`: он выполняет файл целиком и сравнивает вывод с
блоками `%!`. Список проверяемых уроков — `checkedLessons()` в том же файле.
Поэтому урок не может устареть незаметно: любое изменение вывода интерпретатора
сразу роняет проверку.

Ожидания в блоках `%!` и ответы в разделе «Решения» не выдуманы — они сняты с
работающего интерпретатора и проверены.

## Уроки по порядку

| № | Тема | Нужно знать | Что нового |
|---|------|-------------|------------|
| 1 | Факты, запросы, переменные | — | `?`, `_`, атомы, строки, числа |
| 2 | Правила, унификация, перебор | 1 | `:-`, конъюнкция, порядок целей |
| 3 | Арифметика | 1–2 | `#…#`, `СЛОЖЕНИЕ`, `УМНОЖЕНИЕ`, `ЦЕЛВЕЩ` |
| 4 | Рекурсия, отсечение, отрицание | 1–3 | `!`, `НЕ`, `ИЛИ`, `ЛОЖЬ`, `ВЫП` |
| 5 | Списки | 1–4 | `[Г|Х]`, `член`, `присоединить`, сортировки |
| 6 | Строки и тексты | 1–5 | `ДЛИНА`, `КОПИЯ`, `СЦЕП`, `БУКВА`, `ЦИФРА` |
| 7 | Ввод, вывод, диалог | 1–6 | `ВЫВОД`, `ПС`, `ТИХО`, `ВВОД*`, `ВВКОД`, файлы |
| 8 | Поиск по пространству состояний | 1–7 | состояние, ход, цель, память о пройденном |
| 9 | Задачи на ограничениях | 1–8 | `xor/4`, перебор перестановок |
| 10 | Метапредикаты и база знаний | 1–9 | `НАЙТИВСЁ`, `СКОЛЬКО`, `ПРЕДЛ`, `ДОБ`, `УДАЛЕНИЕ` |
| 11 | Модули | 1–10 | `:- ИМПОРТ(...)`, ключ `-I` |
| 12 | Графика | 1–11 | `ТОЧКА`, `ЛИНИЯ`, `ОКРУЖНОСТЬ`, `ЗАКРАСКА`, `ЖДИ` |

Приложение `appendix_debug.pld` — про отладку: трасса, `ТИХО`, версия и разбор
типичных ошибок.

## Прежние уроки

Старые файлы (`lesson_1.pld` … `lesson_9.pld`) лежат в `_old/`. Они устарели:
показывали значения старого интерпретатора, шли не по порядку тем, не содержали
урока про ввод-вывод, а часть из них нельзя было запустить целиком из-за
совпадающих имён предикатов. Новые уроки написаны заново, но выросли из этих
программ; план переписывания — `ai/task_35_lessons_rework.md`, соответствие
файлов — `ai/porting_notes.md`.
