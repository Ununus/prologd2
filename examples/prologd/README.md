# Программы первоначального Пролог-Д

Это копия каталога `src/examples` из репозитория
[`Ununus/prologd`](https://github.com/Ununus/prologd) — того самого движка, который
собирается рядом с нашим под именем `prologd.exe` (опция `-DBUILD_WITH_PROLOGD=ON`,
задача 78).  Закреплённая версия — коммит
`4f8425aa5a427749ea240a7c53e2c5e75142fb52` (`PROLOGD_ENGINE_COMMIT` в корневом
`CMakeLists.txt`).  Копия снята с коммита `7b7f46f…` и сверена с закреплённым:
каталог `src/examples` между ними не менялся (часть 133), поэтому файлы ниже —
по-прежнему байт в байт из оригинала.

Файлы скопированы **как есть**, без правок: это первоначальный диалект, и именно в
таком виде они годятся для сравнения с портом (что и как изменилось — в
`doc/prologd-diff.typ`).  Кодировка у них уже UTF-8, поэтому в редакторе они
читаются нормально.

| Что | Файлы |
|---|---|
| примеры | `factorial.pld`, `file_io.pld`, `findall.pld`, `forall.pld`, `import.pld`, `ranez.pld` |
| уроки первоначального курса | `lessons/lesson 1.pld` … `lessons/lesson 6.pld`, `lessons/lesson 9.pld` |
| библиотека первоначального курса | `lib/library.pld` |

**Наши проверки этих файлов не касаются.**  Они написаны в первоначальном диалекте
(другой конец предложения, другие имена встроенных предикатов), поэтому
`test_formatter.cpp` и `test_queries.py` пропускают всю папку `examples/prologd` —
как они пропускают `examples/lessons/_old`.  Запускать эти программы надо **тем**
движком:

```sh
prologd -s=examples/prologd/factorial.pld
```

Имена файлов оставлены как в оригинале, включая пробелы в именах уроков.
