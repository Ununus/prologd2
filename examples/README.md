# Примеры

Готовые программы на Пролог-Д — их можно запускать как есть:

```sh
prologd -s examples/first_demo.pld
```

## Что где

| Файл | О чём |
|---|---|
| `drawing.pld` | графика: рисунок примитивами (`ТОЧКА`, `ЛИНИЯ`, `ЗАКРАСКА`) |
| `file_io.pld` | файлы: `ЗАПИСЬ_В`, `ЧТЕНИЕ_ИЗ` |
| `findall_demo.pld` | `НАЙТИВСЕ/3` на примере из задания |
| `import_demo.pld` | `ИМПОРТ`: подключение библиотеки из `lib/` |
| `first_demo.pld` | `ПЕРВОЕ` — «взять первое» и «если — то — иначе» |
| `sort_demo.pld` | `СОРТИРОВКА` — порядок и повторы в списке |
| `ground_demo.pld` | `ПОЛНЫЙ` — замкнутый терм и защита перед `ДОБ` |
| `forall_demo.pld` | `ДЛЯВСЕХ` — проверка всех решений сразу |
| `stdlib_demo.pld` | стандартная библиотека `stdlib/`: списки, множества, сортировки (ввод — в `stdlib_demo.input.txt`) |
| `problems/` | задачи: `factorial`, `monk` (Ханойская башня), `monkd` (её же, но ходы вводит человек), `knapsack` |
| `lessons/` | курс: двенадцать уроков и приложение, индекс — `lessons/README.md` |
| `lib/` | библиотека для урока 11 |
| `diamond/` | ромбовидный импорт: один модуль, достижимый тремя путями |

Стандартная библиотека лежит рядом с интерпретатором — в папке
`stdlib`; как её подключить, написано в `stdlib/README.md`.

## Проверка

Уроки и часть примеров обещают свой вывод строками `%!`: `%! С=[1,2,3]` — это
строка, которую напечатает интерпретатор. Такие обещания проверяет
`src/tests/test_lessons.cpp` (`every lesson prints exactly what its comments
promise` и `the example programs print what their comments promise`), поэтому
файл не может устареть незаметно.

Два примера проверяются только разбором: `monk.pld` рисует (а в консоли графика
молчит и остаются одни паузы `ЖДИ`), `monkd.pld` читает ходы с клавиатуры.
`findall_demo.pld` проверяют командные тесты (`src/tests/CMakeLists.txt`).
