# Примеры

Готовые программы на Пролог-Д — их можно запускать как есть:

```sh
prologu -s examples/first.pld
```

## Что где

| Файл | О чём |
|---|---|
| `drawing.pld` | графика: рисунок примитивами (`ТОЧКА`, `ЛИНИЯ`, `ЗАКРАСКА`) |
| `file_io.pld` | файлы: `ЗАПИСЬ_В`, `ЧТЕНИЕ_ИЗ` |
| `findall.pld` | `НАЙТИВСЕ/3` на примере из задания |
| `import.pld` | `ИМПОРТ`: подключение библиотеки из `lib/` |
| `names.pld` | имена: программа в режиме ISO подключает библиотеки в старом формате, каждая со своим маркером имён |
| `first.pld` | `ПЕРВОЕ` — «взять первое» и «если — то — иначе» |
| `sort.pld` | `СОРТИРОВКА` — порядок и повторы в списке |
| `sorting.pld` | приёмы сортировки: шесть учебных реализаций — выбором, вставкой, обменом, разделением, слиянием и деревом |
| `ground.pld` | `ПОЛНЫЙ` — замкнутый терм и защита перед `ДОБ` |
| `forall.pld` | `ДЛЯВСЕХ` — проверка всех решений сразу |
| `stdlib.pld` | стандартная библиотека `stdlib/`: списки, множества, строки, целые числа, имена ISO (ввод — в `stdlib.input.txt`) |
| `problems/` | задачи: `factorial`, `hanoi` (Ханойская башня), `hanoi_play` (её же, но ходы вводит человек), `knapsack` |
| `lessons/` | курс: двенадцать уроков и приложение, индекс — `lessons/README.md` |
| `lib/` | библиотека для урока 11 |
| `diamond/` | ромбовидный импорт: один модуль, достижимый тремя путями |

Рядом ещё две папки:

| Папка | Что там |
|---|---|
| `prologd/` | программы **первоначального** Пролог-Д — копия `src/examples` из `Ununus/prologd` как есть; их запускает `prologd.exe`, новые проверки их не трогают (см. `prologd/README.md`) |
| `iso/` | программы, записанные **именами и знаками ISO**: `arith.pld` — `is`, `=:=`, `=\=`, `\=`; `lists.pld` — `member`, `append`, `length`, `msort`, `sort`; `family.pld` — родословная и `findall`; `order.pld` — `compare/3`, `@<` и две сортировки; `if_then.pld` — `->`; `sub_string.pld` — `sub_string/5`. Запуск: `prologu -I stdlib -s examples/iso/arith.pld` |

Стандартная библиотека лежит рядом с интерпретатором — в папке
`stdlib`; как её подключить, написано в `stdlib/README.md`.

## Проверка

Уроки и часть примеров обещают свой вывод строками `%!`: `%! С=[1,2,3]` — это
строка, которую напечатает интерпретатор. Такие обещания проверяет
`src/tests/test_lessons.cpp` (`every lesson prints exactly what its comments
promise` и `the example programs print what their comments promise`), поэтому
файл не может устареть незаметно.

Два примера проверяются только разбором: `hanoi.pld` рисует (а в консоли графика
молчит и остаются одни паузы `ЖДИ`), `hanoi_play.pld` читает ходы с клавиатуры.
`findall.pld` проверяют командные тесты (`src/tests/CMakeLists.txt`).
