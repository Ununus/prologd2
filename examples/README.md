# Примеры

Готовые программы на Пролог-Д — их можно запускать как есть:

```sh
prologd -s examples/arith.pld
```

## Что где

Программы одного рода устроены одинаково: в шапке — какие предикаты в ней
показаны и как они называются в ISO, потом — что они делают и как запустить
файл, дальше — сами предикаты, вопросы на русском написании и, в конце,
английское имя того же предиката.

| Файл | О чём |
|---|---|
| `arith.pld` | арифметика: `is`, `=:=`, `=\=`, `\=` и запись `#…#` — факториал, сумма списка, НОД |
| `findall.pld` | `НАЙТИВСЕ`, `ВСЕРЕШ`, `МНОРЕШ` (`findall`, `bagof`, `setof`) — вся разница между ними на одних данных |
| `if_then.pld` | `ПЕРВОЕ` (`first`) и знак `->` с ветвью «иначе» |
| `order.pld` | `СРАВНЕНИЕ` (`compare`) и знаки `@<`, `@=<`, `@>`, `@>=`; как этот порядок решает в `СОРТИРОВКА`; и `БОЛЬШЕ` с `МЕНЬШЕ`, которые спрашивают другое |
| `sort.pld` | `МНОЖЕСТВО/2` (`sort`) и `СОРТИРОВКА/2` (`msort`), `СОРТИРОВКА/3` — порядок и повторы |
| `sub_string.pld` | `ПОДСТРОКА/5` (`sub_string`) и `КОПИЯ/4` — подстрока по позиции и по образцу |
| `ground.pld` | `ПОЛНЫЙ` (`ground`) — замкнутый терм и защита перед `ДОБ` |
| `database.pld` | база знаний во время работы: `ДОБ` (`assert`), `ДОБНАЧ`/`ДОБКОН` (`asserta`/`assertz`), `УДАЛЕНИЕ` (`retract`), а также `СКОЛЬКО`, `ПРЕДЛ` и `ТЕРМ` |
| `types.pld` | проверки вида терма: `ПЕР`, `ЦЕЛ`, `ВЕЩ`, `АТОМ`, `СТРОКА`, `СИМВ`, `СПИСОК`, `ПОЛНЫЙ` (`var`, `integer`, `float`, `atom`, `string`, `is_text`, `is_list`, `ground`) и переводы между видами (`X_to_Y`, `atom_string`) |
| `forall.pld` | `ДЛЯВСЕХ` (`forall`) — проверка всех решений сразу |
| `io.pld` | ввод и вывод: `ВЫВОД`, `ВЫВОДПС` (`write`, `writeln`), `ФОРМАТ`, `ВЫВОДФ` (`format_string`, `format`) с местами `{}`, `ВВОДЦЕЛ` (`read_int`) и файлы `ЗАПИСЬ_В`, `ЧТЕНИЕ_ИЗ` (`tell`, `see`) |
| `drawing.pld` | графика: рисунок примитивами (`ТОЧКА`, `ЛИНИЯ`, `ЗАКРАСКА`) |
| `stdlib.pld` | стандартная библиотека `stdlib/`: списки, множества, строки, целые числа, имена ISO (ввод — в `stdlib.input.txt`) |
| `import/import.pld` | `ИМПОРТ`: подключение библиотеки из `import/lib/` |
| `problems/` | задачи: `factorial` (рекурсия), `family` (родословная и `НАЙТИВСЕ`), `hanoi` (Ханойская башня), `hanoi_play` (её же, но ходы вводит человек), `knapsack`, `sorting` (приёмы сортировки: выбором, вставкой, обменом, разделением, слиянием и деревом), `maze` (лабиринт: мышь ищет сыр в ширину и в глубину, с картинкой) |
| `lessons/` | курс: двенадцать уроков и приложение, индекс — `lessons/README.md`; `lesson_11_lib.pld` — библиотека урока 11 |

Рядом ещё папка:

| Папка | Что там |
|---|---|
| `import/` | `ИМПОРТ`: `import.pld` подключает `lib/library.pld` и `lib/hello.pld`, а `diamond/` — ромбовидный импорт: один модуль, достижимый тремя путями |

Стандартная библиотека лежит рядом с интерпретатором — в папке
`stdlib`; как её подключить, написано в `stdlib/README.md`.

## Проверка

Уроки и часть примеров обещают свой вывод строками `%!`: `%! С=[1,2,3]` — это
строка, которую напечатает интерпретатор. Такие обещания проверяет
`src/tests/test_lessons.cpp` (`every lesson prints exactly what its comments
promise` и `the example programs print what their comments promise`), поэтому
файл не может устареть незаметно.

Два примера проверяются только разбором: `hanoi.pld` рисует (а в консоли графика
молчит и остаются одни паузы `ЖДИ`), `hanoi_play.pld` читает ходы с клавиатуры.
Только разбором идут и файлы `import/` — обещаний `%!` у них нет; а ромбовидный
импорт проверяет отдельный тест загрузчика
(`the diamond example loads its shared module once`).
`arith.pld` запускают ещё и командные тесты (`src/tests/CMakeLists.txt`): ими
проверяется, что файл грузится всеми четырьмя способами назвать его в консоли.

`problems/maze/maze.pld` — тот же случай, что `hanoi.pld`: он рисует лабиринт и
идёт мышью по найденному пути, поэтому в списке разбираемых файлов
`src/tests/test_lessons.cpp` стоит без обещаний о выводе.  Ввод он читает сам,
своим вопросом `?ЧТЕНИЕ_ИЗ("maze.input.txt")`, а путь в вопросе считается от
текущей папки — поэтому запускать надо **из папки примера**.  Из корня
репозитория он загрузится и честно ответит `НЕТ`: файл ввода не найден, лабиринта
нет.  Ключ `-i` ему больше не нужен (он был нужен, пока ввод шёл через консоль):

```sh
cd examples/problems/maze
prologd -I ../../../stdlib -s maze.pld
```
